# 수도권에듀잡

서울·경기·인천의 공식 교육 채용정보를 통합 검색하는 프로젝트입니다.

- 경기도교육청 + 경기 25개 교육지원청
- 서울교육일자리포털 + 서울 11개 교육지원청
- 인천광역시교육청 채용공고 + 늘봄지원센터 개인위탁공고(외부강사)
- 지역·학교급·직종 다중 선택 필터
- M0 정비 중에는 Fast freshness watchdog이 검증된 Fast 수집 경로를 필요할 때 dispatch

서비스 건강은 GitHub Actions의 색상이 아니라 공식 source registry 완전성, production freshness, stable-ID reconciliation, publication guard, 공식 원문 표본대조로 판단합니다.

운영·장애대응 절차는 [`docs/RUNBOOK.md`](docs/RUNBOOK.md)를 참고하세요.

공식 채용 조건과 일정은 반드시 원문 공고를 최종 확인하세요.
